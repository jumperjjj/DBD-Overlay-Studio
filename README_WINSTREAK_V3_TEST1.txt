DBD Overlay Studio — WinStreak V3 Test 1
========================================

Reformulacao do WinStreak baseada no visual compacto do 1v1 Timer.

ALTERACOES PRINCIPAIS
- 4 estilos novos: Glass, Split, Minimal e Premium.
- Removido o texto fixo "WIN STREAK" da overlay.
- "Texto superior" configuravel.
- Nome do Killer maior, branco e com glow.
- Foto do Killer maior e centralizada verticalmente.
- Recorde automatico: quando a WinStreak ultrapassa o recorde, o recorde acompanha.
- Zerar a WinStreak nao apaga o recorde.
- Recorde separado e persistente para cada Killer no PC.
- Controle manual do recorde com - / + e botao para resetar o recorde atual.
- "Aplicar" valor exato agora abre uma confirmacao explicando o impacto no recorde.
- Survivor nao reutiliza mais a foto do Killer.
- Survivor possui opcao "Mostrar caixa / imagem do Survivor".
- Com a opcao desligada, nao existe caixa/imagem no lado esquerdo da overlay de Survivor.
- Criada a pasta Survivors para receber as imagens que serao adicionadas depois.
- O seletor de Survivor le automaticamente PNG/JPG/JPEG/WEBP da pasta Survivors.
- Aba WinStreak reorganizada de forma mais compacta: Aparencia a esquerda, Overlay a direita e Estilos abaixo.
- Controles de opacidade/sombra/escala reduzidos para ocupar menos espaco.
- OBS atualizado para o novo tamanho-base do WinStreak (400x230 dentro da fonte 1920x1080).
- Corrigido o servidor local para servir streak-render.css e streak-render.js ao OBS.
