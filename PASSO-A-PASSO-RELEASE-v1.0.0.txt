FISHING CHAT GAME 1.0.0 — ARRASTAR E DAR COMMIT

1. Baixe Fishing-Chat-Game-v1.0.0-GitHub-Automatico.zip em Downloads.
2. Clique com o botão direito no ZIP > Extrair Tudo.
3. Abra a pasta extraída. Você verá .github, src, tests, package.json,
   package-lock.json, INICIAR.bat e os arquivos de orientação.
4. Abra https://github.com/jumperjjj/fishing-chat-game na branch main.
5. Clique em Add file > Upload files.
6. Na pasta extraída, aperte Ctrl+A e arraste TODA A SELEÇÃO para o upload.
   Inclua a pasta .github: é ela que contém o Action pronto.
   Não arraste o ZIP nem a pasta externa: arraste o CONTEÚDO da pasta.
7. Confira na lista do upload estes caminhos:
   .github/workflows/build-windows.yml
   package.json
   package-lock.json
   src/main.js
   tests/first-release.test.js
   Os caminhos devem começar assim, sem uma pasta extra na frente.
8. Escreva Atualizar Fishing Chat Game 1.0.0.
   Escolha Commit directly to the main branch > Commit changes.
9. O workflow Build Windows já está no pacote e começa automaticamente
   quando esse commit chega à main. Não precisa criar ou editar um Action
   separado, publicar um release primeiro ou apertar Run workflow.
10. Abra Actions > Build Windows > a execução do seu commit.
    Aguarde o resultado verde. Abra essa execução e vá até Artifacts.
11. Baixe Fishing-Chat-Game-Windows e extraia o ZIP recebido.
    Dentro estará Fishing-Chat-Game-Setup-1.0.0.exe para instalar e testar.

SE NÃO APARECER A EXECUÇÃO
Confira no repositório se .github/workflows/build-windows.yml foi enviado
no caminho exato. Ele deve conter push com branches: [main].
Confira também se o commit foi salvo na main e se Actions está habilitado
no repositório. A pasta .github do ZIP foi incluída como pasta normal.
Se uma execução aparecer vermelha, abra a etapa vermelha e envie o erro.

DEPOIS, PARA POSTAR O RELEASE
Releases > Draft a new release > crie a tag v1.0.0 com Target main.
Título: Fishing Chat Game 1.0.0.
Use RELEASE-NOTES-v1.0.0.md como descrição e clique em Publish release.
Isso também dispara o Build Windows: quando terminar, o EXE será anexado
automaticamente ao release, em Assets.
Se v1.0.0 já existir, confira que aponta para o código atualizado antes
de publicar. Para apenas testar, use o artifact gerado pelo commit.

RESET SOLICITADO
A primeira abertura da 1.0.0, inclusive por INICIAR.bat, salva um backup
e zera o progresso dos jogadores em todos os canais uma única vez.
Catálogo, imagens, configurações e definições de conquistas são mantidos.
As próximas aberturas mantêm o progresso novo. Se o backup falhar, não limpa.
Preparar e enviar este ZIP não altera seu banco pessoal.

TESTE LOCAL SEM COMPILAR
Feche as versões anteriores e abra INICIAR.bat na pasta extraída.
É necessário Node.js 24. Mantenha o terminal aberto enquanto testa.
Recarregue as fontes do OBS após a atualização.
